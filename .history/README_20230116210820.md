# Plateau NFT 🔥

A decentralized application for minting and trading unique NFTs on the Polygon blockchain.

## Features

- Mint unique NFTs using your own assets or choose from a curated selection of digital art. 🖼️
- Trade NFTs on a built-in marketplace with other users. 💸
- View your NFT collection and manage your ownership of NFTs on the blockchain. 📋

## Getting Started

1. Visit the [Plateau NFT website](https://plateau-nft.com/) to access the application.
2. Connect your wallet to the application using MetaMask or any other Web3 wallet.
3. Start minting or trading NFTs on the marketplace. 🚀

## Installation

1. Install Node.js and npm.
2. Clone the repository: `git clone https://github.com/your-username/plateau-nft.git`
3. Install the dependencies: `npm install`
4. Start the development server: `npm run dev`
